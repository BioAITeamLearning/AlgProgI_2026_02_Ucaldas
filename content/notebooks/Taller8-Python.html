📄 Taller en clase — Python (parte 2)#

Ciclos, listas, match y funciones#

Programación I

Nota. Este taller se resuelve en clase en este notebook de Colaboratory. Los ejercicios están ordenados de menor a mayor dificultad: avanza hasta donde te alcance el tiempo. Escribe tu solución en la celda de código que está debajo de cada enunciado.

Guía rápida#

Ciclo while. Repite el bloque mientras la condición sea verdadera. Con break se sale del ciclo en cualquier momento.

contador = 1
while contador <= 3:
    print(contador)
    contador += 1        # sin esta línea el ciclo nunca termina

while True:              # ciclo infinito: se sale con break
    texto = input("Escriba 'salir': ")
    if texto == "salir":
        break

Ciclo for y range. range(inicio, fin, paso) genera números desde inicio hasta fin - 1.

Instrucción

Valores que toma i

for i in range(5):

0, 1, 2, 3, 4

for i in range(1, 6):

1, 2, 3, 4, 5

for i in range(0, 10, 2):

0, 2, 4, 6, 8

for i in range(5, 0, -1):

5, 4, 3, 2, 1

El for también recorre directamente un texto (letra por letra) o una lista (elemento por elemento):

for letra in "hola":
    print(letra)

Listas. Guardan varios valores en una sola variable. Las posiciones empiezan en 0.

frutas = ["mango", "pera"]
frutas.append("uva")      # agrega al final -> ["mango", "pera", "uva"]
print(frutas[0])          # mango
print(len(frutas))        # 3
for f in frutas:          # recorre los elementos
    print(f)
for i in range(len(frutas)):   # recorre las posiciones
    print(i, frutas[i])

match (el switch de Python). Compara un valor contra varios casos. case _ es el caso por defecto y | une varios valores en un mismo caso.

match opcion:
    case 1:
        print("Uno")
    case 2 | 3:
        print("Dos o tres")
    case _:
        print("Otro valor")

Funciones. Se definen con def. Una función puede no retornar nada (solo hace algo, como imprimir) o retornar un valor con return.

def saludar(nombre):          # no retorna: solo imprime
    print("Hola,", nombre)

def cuadrado(x):              # retorna un valor
    return x * x

saludar("Ana")
resultado = cuadrado(4)       # resultado vale 16

Ciclo while#

Ejercicio 1#

Pide un número entero positivo n y, usando un ciclo while, imprime una cuenta regresiva desde n hasta 1. Al final imprime ¡Despegue!. Por ejemplo, con n = 5:

5 4 3 2 1 ¡Despegue!

Ejercicio 2#

Pide una nota. Mientras la nota esté por fuera del rango de 0.0 a 5.0, muestra Nota inválida, intente de nuevo y vuelve a pedirla. Cuando sea válida, imprime Aprobó si es mayor o igual a 3.0 o Reprobó en caso contrario.

Prueba ingresando 7, luego -1 y luego 3.4.

Ejercicio 3#

Pide un número entero positivo e imprime cuántos dígitos tiene y cuánto suman sus dígitos. Por ejemplo, para 4825:

Dígitos: 4 Suma: 19

Tip. n % 10 te da el último dígito y n // 10 le quita el último dígito al número. Repite hasta que el número llegue a 0.

Ciclo for y range#

Ejercicio 4#

Usando for y range (sin listas), imprime en una línea cada una de estas secuencias:

  1. Los números pares del 2 al 20.

  2. Los números del 10 al 1, en orden descendente.

  3. Los múltiplos de 5 desde 5 hasta 50.

Después pide un número n e imprime la suma de los números de 1 a n. Con n = 5 la suma es 15.

Ejercicio 5#

Pide un número entero n (mayor o igual a 0) e imprime su factorial usando un ciclo for. El factorial de n es el producto 1 × 2 × ... × n, y el factorial de 0 es 1. Por ejemplo, 5! = 120.

Ejercicio 6#

Pide una palabra y, recorriéndola con un for letra por letra, construye la palabra al revés. Imprímela e indica si es un palíndromo (se lee igual al derecho y al revés). Por ejemplo:

radar -> es palíndromo
nohtyp -> no es palíndromo

Listas#

Ejercicio 7#

Crea una lista de compras vacía. Pide nombres de productos uno por uno y agrégalos a la lista con append, hasta que el usuario escriba fin. Al final imprime la lista numerada y cuántos productos tiene. Por ejemplo:

1. arroz
2. leche
3. pan
Total de productos: 3

Ejercicio 8#

Dada la lista de notas:

notas = [3.5, 4.2, 2.8, 4.9, 1.7, 3.0]

Recorriéndola con un ciclo (sin usar sum, max ni min), calcula e imprime:

  1. El promedio de las notas.

  2. La nota mayor y la nota menor.

  3. Una nueva lista solo con las notas aprobadas (mayores o iguales a 3.0) y cuántas son.

Ejercicio 9#

Calculadora. Pide dos números y un operador (+, -, * o /). Usa match para hacer la operación correspondiente e imprimir el resultado. Si el operador no es ninguno de los cuatro, imprime Operador no válido. Si se intenta dividir entre cero, imprime No se puede dividir entre cero.

Ejercicio 10#

Pide un número del 1 al 7 y usa match para imprimir el día de la semana (1 = Lunes, …, 5 = Viernes). Para el 6 y el 7 imprime Fin de semana usando un solo case con |. Para cualquier otro número imprime Día inválido.

Funciones#

Ejercicio 11#

Escribe estas cuatro funciones y pruébalas llamándolas con distintos valores:

  1. saludar(nombre): no retorna nada; imprime Hola, <nombre>. ¡Bienvenido a Python!.

  2. linea(n, caracter): no retorna nada; imprime el carácter repetido n veces. linea(10, "*") imprime **********.

  3. area_rectangulo(base, altura): retorna el área.

  4. es_par(n): retorna True si n es par y False si no.

¿Qué se imprime si haces print(saludar("Ana"))? Explica por qué.

Reescribe el Ejercicio 8 usando funciones que reciban una lista y retornen el resultado:

  • promedio(lista)

  • mayor(lista)

  • contar_aprobados(lista)

Prueba tus funciones con la lista del Ejercicio 8 y con otra lista inventada por ti.

Reto#

Ejercicio 13#

Construye un conversor de unidades con un menú que se repita con while True hasta que el usuario elija 0:

===== CONVERSOR =====
1. Celsius a Fahrenheit
2. Fahrenheit a Celsius
3. Kilómetros a millas
0. Salir

  • Usa match para atender la opción elegida. Si la opción no existe, muestra Opción inválida.

  • Cada conversión debe ser una función que retorne el resultado: F = C × 9 / 5 + 32, C = (F − 32) × 5 / 9 y millas = km × 0.621371.

  • Muestra los resultados con dos decimales. Por ejemplo, 100 °C son 212.00 °F y 10 km son 6.21 millas.
